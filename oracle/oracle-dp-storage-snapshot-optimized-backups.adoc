= Backup ottimizzati per le snapshot di storage
:allow-uri-read: 


[role="lead"]
Oracle Snapshot Optimized Backups era un metodo di point-in-time recovery che ti permetteva di eseguire un ripristino usando gli snapshot senza mettere il database in modalità di hot backup.

Gli utenti possono comunque ripristinare i dati dagli snapshot senza utilizzare la modalità di backup, ma è supportato solo il ripristino completo tramite la funzione RECOVERY AUTOMATIC. Il ripristino incompleto utilizza il metodo SNAPSHOT TIME per indicare l'ora di creazione dello snapshot.
